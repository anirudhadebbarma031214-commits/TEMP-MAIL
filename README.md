# TEMP-MAIL

A responsive disposable-email website using the public mail.tm API.

## Features
- Create disposable mailboxes
- Copy address, refresh inbox, read messages, and delete messages
- Responsive neon-dark design

## GitHub Pages
Open Settings > Pages. Choose Deploy from a branch, branch `main`, folder `/(root)`, and save.

## Provider notes
Uses https://api.mail.tm. Provider uptime, domains, and rate limits are controlled by mail.tm. Do not use disposable inboxes for sensitive information.
